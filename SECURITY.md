# Security

- Report vulnerabilities in Scorensic privately via GitHub Security Advisories on this repository.
- Scorensic executes grader code. It is **not a sandbox**; audit untrusted graders only inside a container or VM.
- If Scorensic finds an exploitable grader flaw in a live third-party benchmark, disclose it to that benchmark's maintainers first and allow reasonable time (90 days) before publishing details.
